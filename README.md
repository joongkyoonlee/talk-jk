# 📣 실시간 소통방 (Talk-JK)

강사와 수강생이 실시간으로 메시지·의견·익명투표를 주고받을 수 있는 라이브 커뮤니케이션 웹앱입니다.
별도 회원가입 없이 **방 이름 + 패스코드**만으로 즉시 입장할 수 있으며, 모든 데이터는 Lovable Cloud(Supabase)에 안전하게 저장되고 실시간으로 동기화됩니다.

🔗 **라이브 데모:** https://talk-jk.lovable.app

---

## ✨ 주요 기능

### 👨‍🏫 강사 (Instructor)
- **소통방 개설**: 주제·방 이름·강사 닉네임·4자리 패스코드 설정
- **공지 고정**: 방 상단에 고정 공지 등록 (PINNED 배지 표시)
- **메시지 전송**: 텍스트 + 이미지 (최대 20MB, JPG/PNG/WEBP/GIF)
  - 클립보드 캡쳐 이미지 **Ctrl/Cmd + V** 붙여넣기 지원
  - URL 자동 링크화
  - "공지" / "일반" 메시지 타입 선택
- **의견에 답변 달기**: 수강생 의견에 강사 답변 등록
- **익명투표 생성/마감**: 객관식 투표 항목을 만들고 실시간 결과 확인

### 🙋 수강생 (Participant)
- **간편 입장**: 방 이름 + 패스코드 + 닉네임만으로 입장
- **의견 등록**: 카테고리(질문/제안/공감 등)별로 분류된 의견 제출
- **익명투표 참여**: 클라이언트당 1회 투표 (익명 보장)
- **실시간 업데이트**: 새 메시지/공지/투표가 즉시 반영

### 🛠️ 관리자 (Admin)
- `/admin` 경로에서 비밀번호 입장
- 전체 소통방 목록 조회 (주제·강사·패스코드·생성일)
- 소통방 일괄 삭제 (연결된 메시지·의견·투표 자동 정리)

## 🚀 사용법

### 1. 소통방 만들기 (강사)
1. 홈 화면에서 **"소통방 개설"** 선택
2. 다음 정보 입력:
   - **주제**: 강의/회의 주제 (예: "AI 워크숍 1주차")
   - **방 이름**: 입장 시 사용할 식별자 (예: "ai-class")
   - **강사 닉네임**: 메시지에 표시될 이름
   - **패스코드**: 4자리 숫자 (수강생에게 공유)
3. 개설 완료 후 헤더에 표시되는 **방 이름과 패스코드**를 수강생에게 안내

### 2. 소통방 입장하기 (수강생)
1. 홈 화면에서 **"소통방 입장"** 선택
2. 강사가 알려준 **방 이름**과 **패스코드** 입력
3. 본인의 **닉네임** 입력 후 입장

### 3. 탭 사용하기
| 탭 | 설명 |
|---|---|
| 💬 **메시지** | 강사 메시지·공지·이미지 실시간 확인 |
| 💡 **의견** | 수강생이 카테고리별로 의견 등록, 강사가 답변 가능 |
| 📊 **익명투표** | 강사가 만든 투표에 1회 참여, 결과 실시간 표시 |
| 👥 **참여자** | 현재 방에 접속한 참여자 목록 |

### 4. 이미지 첨부 팁 (강사)
- 파일 선택 버튼으로 업로드, **또는**
- 텍스트 입력창에서 **Ctrl + V (Mac: Cmd + V)** 로 캡쳐 이미지를 바로 붙여넣기
- 최대 20MB, JPG/PNG/WEBP/GIF 지원

### 5. 관리자 페이지
- 주소창에 `/admin` 입력 → 관리자 비밀번호 입장
- 전체 소통방 현황 확인 및 불필요한 방 삭제

## 🧱 기술 스택

- **Frontend**: React 18 + Vite 5 + TypeScript 5
- **Styling**: Tailwind CSS v3 + shadcn/ui (Radix UI)
- **Backend**: Lovable Cloud (Supabase: Postgres + Realtime + Storage)
- **Routing**: React Router v6
- **State/Data**: Supabase Realtime 구독 기반 라이브 동기화

## 💻 로컬 개발

```bash

npm install   # 또는 bun install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```
